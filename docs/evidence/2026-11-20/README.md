# Correctness convergence and controlled speech evidence

`summary.json` identifies the exact source revision and hashes the artifacts.
These reruns supplement the historical November 19 evidence; they do not
retroactively qualify later code through earlier CI results.

The original failure demonstrates false clipping and reference-generation flags
while missing-reference bypass copied unchanged F32 audio. Windows core and
installed-consumer reruns and Linux ARM64 sanitizer reruns cover the correction.
The default build still has no required third-party DSP dependency.

`controlled-doubletalk-portable.json` was generated by `tools/controlled_aec.py`
against the native Release tool. It includes upstream recording hashes and the
native executable hash, without redistributing source or derived audio. Its
same-clock synthetic echo is a controlled experiment with recorded speech,
not a physical-room measurement. The original 8 dB raw-component SNR improvement
target failed and remains failed. The backend-processed near control diagnoses
signal conditioning; it does not replace the target or prove speech quality.

No physical-device, audible-tail, inference-contention or ABI-stability claim
is made. Current CI results remain separate from locally executed verification.
